## Why Reader

Reader is a desktop app built with Tauri + React for serious reading and knowledge work.

It combines:

- A clean library and reading experience
- Strong Markdown/PDF/EPUB support
- AI workflows that can run locally
- MCP integration for external assistants

## Recent Focus

Recent updates improved three areas:

- Markdown reading with `Text Parse` and `Multimedia Parse`
- Reading-comprehension workflows with `Understand` and `Glossary`
- Library organization with document tags, batch review, and related-document discovery
