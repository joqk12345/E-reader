# Guide

Reader is a local-first reading app for EPUB, PDF, and Markdown with built-in AI workflows.

## Core capabilities

- Library management for EPUB/PDF/Markdown
- Semantic paragraph search
- Translation and bilingual reading
- Context chat, deep analysis, and notes
- Audiobook / TTS with sentence follow
- MCP integration for external AI assistants

## Architecture snapshot

- Desktop shell: Tauri 2 (Rust)
- Frontend: React + TypeScript
- Local embedding: `@xenova/transformers`
- Storage: SQLite
