# Workspace、语义搜索、阅读页与 Settings 设计提案

状态：提案，待视觉评审；不是已实现或已验收的 ADR。
日期：2026-09-12

## 工作项

WI-DESIGN-016：记录首页及语义搜索设计，并提出阅读页和 Settings 的后续评审方案。
本次仅文档变更，免行为 red；最终仍运行 exact-tree gate。不得把工作树中已有的 UI 修改算作本提案实现。

## 原则与边界

参考 The Non-Designer's Design Book 的 Contrast、Repetition、Alignment、Proximity。
参考截图明确是 Apple Books Home 的局部滚动视图，不能据此推断阅读页；借鉴导航职责分离，不照搬大型目标看板。
减少结构层级而非一律缩小 padding；组内紧、组间清楚，保留正文可读性。
所有实现值必须使用 tokens.css 命名 tokens；不改变数据库、IPC、publication、Locator、安全、AI 或搜索合同。

## 首页：书库即首页

- 不增加独立 Home 页面、推荐看板或第二套最近阅读。
- 单一顶部任务栏：Library、书名/作者搜索、导入、更多；品牌只出现一次。
- 侧栏承载全部、收藏、最近、格式、更多筛选及语义搜索入口。
- 继续阅读改为紧凑行；无记录省略，搜索或筛选时让位给结果。
- 默认文档列表，保留 Grid/Compact；排序和视图靠近列表。
- 批量标签和标签管理渐进披露；键盘与触屏不能依赖悬停。
- 候选密度：顶部 48px、侧栏 184px、内容边距 16px、继续阅读及默认文档行约 64px。这些是待验证目标，不是硬性裁切高度。

## 语义搜索首页

代码依据：SemanticSearchHome.tsx、SearchPanel.tsx。
当前存在独立历史侧栏和输入下历史标签的重复，以及外部卡片与内部工具区嵌套。

- 共享工作区外壳，删除独立历史侧栏和装饰性卡片。
- 搜索区靠上、左对齐：简短用途说明、查询输入、搜索按钮。
- 保留多行输入能力；不强制三行空输入，不做居中欢迎大屏。
- 范围与实际本地/远程模式紧随输入；数量选项收进搜索选项。
- 最近搜索仅一份，默认三条，可展开及清除；无历史直接省略。
- 示例只提示，不自动提交。
- 搜索后输入位置稳定，引导及历史让位给结果列表。
- 每条结果组织为来源、片段、打开原文；来源依据现有可用字段，不伪造 metadata。
- 不把相似度百分比表现为正确率；可在详情标作相关性分数。
- 不做没有精确匹配依据的关键词高亮。
- 首次进入、搜索中、无结果、失败必须区分；保留查询及重试入口。
- 索引过期或不完整明确警告；本地模型缺失保留显式下载操作，不自动下载。
- 远程模式及关键词降级可见；维护入口只提供实际支持的作用范围。

## 阅读详情页：提案

代码依据：Reader.tsx；当前已有 TOCPanel、ToolPanel、紧凑 header、阅读模式和工具折叠能力。

- 不新增文档详情中间页，书库/搜索结果直接进入现有阅读流程。
- 唯一顶部控制栏：返回、可截断文档标题、目录、阅读外观、工具、更多。
- 标题采用可收缩布局槽，避免绝对居中标题与左右操作在窄窗口相撞。
- 不保留书库导航侧栏；目录与辅助工具延续已有开关及用户状态，不擅自重置已保存偏好。
- 阅读正文为视觉主角；侧面板仅一个紧凑标题区，减少内部重复标题、边框、卡片。
- 目录与当前章节邻近；理解、笔记、标注、TTS 等保持现有能力与分组，可按需展开。
- 不为填满空间无限拉宽正文，不改变字号、行高、主题或阅读位置语义。
- 搜索跳转保留原文定位，不在本轮承诺尚未实现的返回搜索上下文功能。

## Settings：提案

代码依据：Settings.tsx。现有导航已分为 Reading、Assistive tools、Workspace、Reader；外层弹窗约 900px 宽、78vh 高，侧栏 208px。主要重复来自品牌文案、Settings 标题、eyebrow、hero 分区标题和说明。

- 保留单一设置弹窗和已有分类，不另增设置首页或全局导航。
- 左侧以 Settings 身份和紧凑分类导航替代品牌广告语。
- 右侧顶部仅当前分区名及关闭按钮；删除重复 eyebrow、hero 标题和泛泛描述。
- 内容以分组标题、设置行、细分隔线组织，不每项套卡片。
- 标签和必要说明左对齐，控件共用右侧对齐列；长说明及窄窗口上下排列，不能裁切控件。
- 外观分开标明应用主题与阅读主题，并保留精简预览。
- AI 与 Embedding 可在同页明确分组：生成模型用于理解/翻译，Embedding 用于语义检索；不引入新 provider 或改变配置合同。
- 音频显示当前 provider 的主要配置，其余按需展开；切换不丢失已有值。
- MCP、自动批准编辑等权限选项保留风险说明，不能因低频而隐藏关键后果。
- API key 默认遮蔽，不出现在日志、提示或预览。
- 明确即时生效项与需保存项：目前应用主题即时生效，不能伪装为统一保存事务。
- 底部固定保存区承载需保存项与保存结果；Reload 如保留必须说明重载配置的作用，不能当作普通刷新。
- 不将关闭按钮称为取消，除非已实现对应回滚语义。未保存离开确认属于后续行为工作项，需单独 red。

## 后续验收与非目标

- 同窗口对比顶部占用、首条文档/结果位置及可见行数。
- 1024/1280/1440px、200% 缩放、长标题、空数据、键盘导航及焦点回归。
- Reader 保留 Locator、阅读位置、目录、搜索跳转、工具及主题隔离。
- Settings 测试即时生效、保存成功/失败、关闭和重载的真实语义；不默改持久化模型。
- 语义搜索覆盖无模型、不完整索引、远程、关键词降级、失败和原文跳转。
