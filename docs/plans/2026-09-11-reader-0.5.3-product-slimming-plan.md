# Reader 0.5.3 产品精简计划：移除 PDF，聚焦 EPUB 与 Markdown

- 状态：**Active / ready for implementation**
- 日期：2026-09-11
- 依据：[`ADR-006`](../adr/006-product-slimming-epub-markdown.md)
- 目标版本：0.5.3

## 目标

移除低使用率 PDF Feature，降低产品、依赖和维护复杂度；将投入集中到 EPUB 和 Markdown 的稳定阅读，以及搜索、翻译、AI、笔记、标注和 TTS。

## 总体边界

### 删除

- PDF 导入、解析、阅读、预览和格式专用 UI；
- PDF React/Rust 分支、Tauri commands、adapter、依赖和注册；
- PDF 单元测试、fixture、UI smoke mock、设置项、筛选器和文档入口。

### 保留

- EPUB 安全导入、sanitized render、资源隔离、TOC、Locator 和阅读位置；
- Markdown 导入、结构化渲染、TOC、搜索和阅读位置；
- 搜索、翻译、摘要、理解、聊天、词典、TTS、笔记、标注和阅读主题；
- 历史 PDF 数据行的读取兼容、unsupported 状态和删除操作。

### 非目标

- 不改变 EPUB/PDF/Markdown 以外的数据库迁移合同；
- 不删除、覆盖或转换历史 PDF 原始文件；
- 不重写 EPUB、AI、Locator 或 sanitizer；
- 不新增格式转换、云同步或大规模 UI 重构。

## 工作包

### WI-01：PDF 依赖与代码盘点

验收：建立清单覆盖 React、Rust、commands、注册、依赖、数据库字段、测试、fixture、mock、文档和 UI 入口；标出必须保留的历史 PDF 兼容边界。

非目标：本 WI 不删除产品代码。

### WI-02：测试先行与兼容边界

先增加行为测试，覆盖：

- 导入选项和格式筛选不再出现 PDF；
- PDF 不能进入新的阅读流程；
- 历史 PDF 显示“不再支持 PDF”且可删除；
- EPUB/Markdown 正常导入和打开；
- 删除 PDF 实现后不存在残留 command、parser、adapter 或 UI 入口。

需要为 mock Tauri/数据库边界命名真实 integration/e2e 配对；不能只断言 mock 被调用。

### WI-03：移除 PDF 实现

删除 PDF parser、reader branch、preview、command、注册、adapter、依赖、fixture 和无用测试。保留最小历史记录 guard，禁止旧 PDF 进入 EPUB/Markdown adapter。

验收：TypeScript、Rust 编译通过，搜索清单中的 PDF 实现只剩兼容 guard、迁移说明和必要的历史数据测试。

### WI-04：历史数据安全降级

实现历史 PDF 的明确 unsupported 状态：

- 页面显示“不再支持 PDF”；
- 提供删除入口；
- 不解析、不转换、不覆盖原始文件；
- 数据库读取失败时仍有可理解的错误状态。

验收：已有 PDF document 不导致 Library、启动和删除流程崩溃。

### WI-05：EPUB/Markdown 回归与文档

验证并更新 README、FEATURES、CHANGELOG、RELEASE 和相关帮助文案，明确 Reader 聚焦 EPUB + Markdown。补充保留能力回归证据。

验收：EPUB/Markdown 的导入、阅读、TOC、阅读位置、搜索、翻译、AI、笔记、标注和 TTS 均通过相关测试。

### WI-06：发布验证

同步版本为 0.5.3，记录依赖与构建产物变化，完成发布前 gate。除非所有验收条件通过，不创建 release tag。

## 测试矩阵

| 场景 | Lane | 核心断言 |
|---|---|---|
| 导入选项/格式筛选 | frontend-unit/component | 无 PDF 入口，EPUB/Markdown 仍存在 |
| 历史 PDF Library 行 | frontend + integration | 显示 unsupported，不触发 reader adapter |
| 历史 PDF 删除 | integration | 删除 document 按既有语义执行，原始文件不被覆盖 |
| EPUB/Markdown 打开 | UI/e2e | 首屏、TOC、位置和基础操作正常 |
| PDF 实现残留扫描 | guardian | 无 PDF command/parser/adapter/fixture 残留 |
| 依赖与构建 | build/rust | 无未使用 PDF 依赖，TypeScript/Rust 编译通过 |
